# site（旧URLの転送用）

南信模型クラブのサイトは `https://nanshin-modelers-club.github.io/` に移転しました。
サイト本体のリポジトリは [nanshin-modelers-club.github.io](https://github.com/nanshin-modelers-club/nanshin-modelers-club.github.io) です。

このリポジトリは、旧URL（`/site/`）へのアクセスを新URLへ転送するためだけに残しています。
旧URLが使われなくなった頃（目安：2027年前半）に、アーカイブまたは削除してかまいません。
